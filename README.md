# 📝 Flutter Quiz App

A fun and interactive way to learn Flutter! This app is a small, playful project designed to test and reinforce your existing Flutter knowledge through a series of multiple-choice questions.

## 🚀 Features

- **Dynamic Questions**: A variety of Flutter-related topics to challenge your brain.
- **Real-time Feedback**: See instantly which answers were correct or incorrect on the results screen.
- **Custom UI**: Beautifully styled components including a custom question identifier and smooth gradients.
- **Restartable**: Easily restart the quiz to improve your score.

## 📸 Preview

- **Start Screen**: Welcome screen with a fun logo and clear call-to-action.
- **Quiz Screen**: Clean layout for questions and shuffled answer buttons.
- **Results Screen**: A summary of your performance with a scrollable overview of all questions.

## 🛠️ Installation

1.  **Clone the repository**:
    ```bash
    git clone [https://github.com/your-username/flutter_quizapp.git](https://github.com/your-username/flutter_quizapp.git)
    ```
2.  **Navigate into the directory**:
    ```bash
    cd flutter_quizapp
    ```
3.  **Install dependencies**:
    ```bash
    flutter pub get
    ```
4.  **Run the app**:
    ```bash
    flutter run
    ```
